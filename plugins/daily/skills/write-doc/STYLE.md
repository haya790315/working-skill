# STYLE — 留什么、删什么、怎么写

## 1. 因果留，来历删

文档的读者没参与过那场讨论。判定每一句话的去留，只问一句：

> **把这句话拿掉，读者会不会把它「修回去」？**

会 → 留（这是**因果**）。不会 → 删（这是**来历**）。

| | 定义 | 例 |
| --- | --- | --- |
| **因果**（留） | 现在为什么是这个样子，不知道就会踩坑 | 改名が起きるため日本語名は保存しない |
| **来历**（删） | 谁、何时、经过什么讨论、曾经考虑过什么 | 2026-09-07 の MTG で確定。当初は別案だった |

因果用**现在时、一句话**写在它该出现的地方，不另开「経緯」章节。
值得长篇说明的决策 → 依 `/design:adr` 另立 ADR，正文只留一行链接。

## 2. 对话痕迹：出现即删

| 类别 | 例 | 怎么办 |
| --- | --- | --- |
| 检讨过程 | 検討した結果 / 経緯 / 当初は X を考えたが / 我们讨论后决定 | 只留结论，理由压成一句因果 |
| 会话指示语 | 今回は / 先ほどの / 上で述べたように / 接下来我会 / 让我们 | 直接删。文档没有「刚才」，读者是跳着看的 |
| 不确定 | 〜と思われます / おそらく / 应该可以 / 大概 | 去验证；验证不了就列进 `未確認`，不写进正文 |
| 自我评价 | エレガントな設計 / 非常强大 / 完美解决 / robust, seamless | 直接删，不构成信息 |
| 寒暄收尾 | 以上です / ご参考まで / 希望这份文档对你有帮助 | 直接删 |
| 变更叙事 | 〜を実装しました / 本次修改新增了 | 文档写「现在是什么」，不写「做了什么」。那是 PR 的事 |

### 改写对照

| ❌ | ✅ |
| --- | --- |
| 検討した結果、パフォーマンスの観点から Redis を採用することにしました。 | キャッシュは Redis。理由は [ADR-0007](../adr/0007-cache-redis.md)。 |
| 今回の変更で、認証処理を middleware に移しました。 | 認証は middleware（[auth.ts:12](../src/auth.ts#L12)）で行う。 |
| おそらく 5 分程度で完了すると思われます。 | 所要時間：約 5 分（実測 4 分 30 秒）。 |

## 3. 用语

- **专有名词第一次出现时给一句定义**，或链到定义它的地方。`SM（センサーモジュール）` 这种括号就够。
- **同一个概念只用一个词**。同一份文档里不要混用「ユーザー／利用者／アカウント」。跟随项目既有叫法。
- **不用抽象名词当主语**。「最適化が行われる」→「バッチが古いレコードを削除する」。
- **形容词换成数值**。「高速」→「p95 200ms 以下」；「たまに失敗する」→「1 日 1〜2 件失敗する」。
- **写现状用现在时、主动语态**。

## 4. 标题

- **标题写结论或动作，不写话题名。**读者只扫标题也要能猜到内容。
  - ❌ `## ログについて` / `## 概要` / `## その他` / `## 注意事项`
  - ✅ `## ログは CloudWatch に 30 日保存される` / `## 1. サービスアカウントを作る`
- 手顺用 **数字 + 动词**开头。
- 同一层级的标题保持同一句式：要嘛全是动作句，要嘛全是结论句，不混着来。
- 标题层级变深，通常是在同一个文件里回答了两类问题的信号 → 看 Step 1 的章节职责表，把它搬到该去的章节，原处留一行链接。

## 5. 段落

- **一段只讲一件事。**讲到第二件事就换段。
- 并列的项目 → 列表；每项有两个以上属性 → 表格。散文只留给表格装不下的东西。
- 每节把结论放最前面，背景与例外放后面。
- 段落之间不写过渡句。文档靠标题导航，不靠行文连贯。
- 粗体只给「不照做会出事」的地方；一节里到处都是粗体等于没有粗体。
- 警告用固定写法，不用 emoji 堆砌：

  ```md
  > **注意**：このコマンドは本番データを削除する。
  ```

## 6. 链接与代码引用

- 指向代码用可点击的相对链接：`[auth.ts:42](../src/auth.ts#L42)`。
- 数值、常量、选项一览不要转抄进文档，用指向代码的链接代替——转抄的那一刻就开始过时。
- 「詳細は別文書を見よ」要写清楚**去那里能得到什么**：
  - ❌ `詳細は setup.md を参照。`
  - ✅ `必要な IAM 権限の一覧は [初回セットアップ](./初回セットアップ.md#前提条件) にある。`
