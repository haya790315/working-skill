# work-report

## 概要

対話記録を読んで、今何をやっているか・何が終わったかを **3〜5行の短文** でまとめる。
Slack や口頭報告のコピペ素材として使えるレベルのテキストを出力する。

## 出力フォーマット

```
【作業報告】

📌 {チケット番号}：{機能の概要（ビジネス言葉）}

- ✅ / 🔄 / ⬜ 仕様確認・設計
- ✅ / 🔄 / ⬜ 実装
- ✅ / 🔄 / ⬜ 動作確認

{何が確認できたか・保証できたかを1〜2文で}
```

**フォーマット上の注意:**
- ステータスは `✅ 完了 / 🔄 進行中 / ⬜ 未着手` で表現する
- チケット番号がなければ機能名だけでよい
- 技術用語（ファイル名・メソッド名・テスト名など）は省く
- ビジネス文脈で「何が保証できたか」を中心に書く

## 生成ルール

1. **情報源**: 対話記録全体を通読する
2. **現在進行中の判定**: 対話の末尾（直近のやりとり）で取り組んでいる内容を「対応中」とする
3. **完了の判定**: commit・マージ・完了確認が確認できた内容だけを「完了済み」に含める
4. **文体**: 体言止めまたは「〜しました」調のビジネス日本語。敬体・簡潔に
5. **出力のみ**: ファイルには保存しない

## 実行手順

1. 対話記録を末尾から逆順に読み、直近の作業を把握する
2. さらに全体を通読し、完了済み作業を抽出する
3. フォーマットに従って短文を生成し、対話ウィンドウに出力する
